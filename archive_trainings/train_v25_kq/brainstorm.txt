## Các vấn đề cần xem xét

**1. `use_bias=True` trong Conv1D + BatchNormalization là dư thừa**

BatchNorm đã trừ mean nên bias trong Conv1D hoàn toàn vô hiệu quả. Bỏ `use_bias=False` trong tất cả Conv1D đứng trước BN để tiết kiệm tham số mà không ảnh hưởng gì:

```python
x = Conv1D(32, kernel_size=7, strides=s, padding='same',
           use_bias=False)(x)  # ← bỏ bias
x = BatchNormalization()(x)
x = Activation('relu')(x)     # ← activation ra sau BN
```

**2. `activation='relu'` đặt sai vị trí — nên sau BN**

Thứ tự chuẩn theo ResNet gốc (và các biến thể tốt hơn) là `Conv → BN → ReLU`, không phải `Conv(relu) → BN`. Khi relu nằm trước BN, phân phối đầu vào của BN bị lệch (chỉ còn phần dương), làm giảm hiệu quả normalization.

**3. Kernel size 7 có thể quá lớn ở các block cuối**

Sau 2 lần stride=2 và MaxPool ban đầu, temporal dimension chỉ còn 25 samples. Kernel size 7 lúc này cover gần 1/3 chuỗi — receptive field rất lớn nhưng thêm compute. Cân nhắc giảm xuống 5 hoặc 3 ở block 2-3:

```python

```

**4. Dropout không nhất quán trong SE Block**

SE Block dùng Dense nhưng không có regularization, trong khi các Conv có Dropout 0.2. Với dataset nhỏ điều này không ảnh hưởng nhiều, nhưng nên thống nhất.

**5. MaxPool1D ngay đầu trước khi học bất kỳ feature nào**

## 1. Thay SE Block Dense bằng Conv 1×1 — thay đổi quan trọng nhất

SE Block hiện tại dùng `Dense` layer, không có trong danh sách tối ưu của ESP-NN. Trong khi đó `Conv1D` với `kernel_size=1` (tương đương pointwise/1×1 conv) được tăng tốc **14.2×** — cao nhất toàn bảng. Cần reshape để biểu diễn SE dưới dạng conv:

```python
def se_block_conv(input_tensor, c=32, ratio=4):
    # GAP → (batch, 1, c)
    se = tf.reduce_mean(input_tensor, axis=1, keepdims=True)
    # Dùng Conv1D(kernel=1) thay Dense → được ESP-NN tăng tốc 14×
    se = Conv1D(c // ratio, kernel_size=1, use_bias=False)(se)
    se = Activation('relu6')(se)           # relu6 được tăng tốc 11.5× !
    se = Conv1D(c, kernel_size=1, use_bias=False)(se)
    se = Activation('sigmoid')(se)
    return Multiply()([input_tensor, se])  # elementwise_mul: 3.5×
```

---

## 2. Thay ReLU bằng ReLU6 — miễn phí

`PReLU / ReLU6` đạt **11.5×** tăng tốc. Trong khi `ReLU` thông thường không có entry riêng trong bảng, nghĩa là có thể nó dùng đường fallback ANSI C. Đổi toàn bộ sang `relu6`:

```python
x = Conv1D(32, kernel_size=7, strides=s, padding='same', use_bias=False)(x)
x = BatchNormalization()(x)
x = Activation('relu6')(x)   # thay 'relu' → 'relu6', tăng tốc gần 11.5×
```

---

## 3. Depthwise Separable Conv thay Conv1D tiêu chuẩn

Conv1D 7-kernel với 32 channel hiện tại rất nặng. Depthwise conv được tăng tốc **4.5–6.3×** và giảm FLOPs đáng kể. Với 1D signal, có thể dùng `SeparableConv1D` (= depthwise + pointwise):

```python
# Thay Conv1D(32, 7) bằng:
x = SeparableConv1D(32, kernel_size=7, strides=s, padding='same', use_bias=False,
                    depthwise_initializer='he_normal')(x)
# SeparableConv = depthwise (6.3×) + pointwise/1×1 conv (14.2×)
# Giảm params: 7×32×32 = 7168 → 7×32 + 32×32 = 1248 params (~5.7× ít hơn)
```

---

## 4. Loại AvgPool khỏi head — thay bằng GAP qua reduce_mean

`avg_pool` chỉ đạt **3.6×** còn `max_pool` đạt **7.8×**. `GlobalAveragePooling1D` trong Keras thường compile thành một vòng lặp reduce, không phải `avg_pool` kernel được tối ưu. Nếu profiling cho thấy GAP chiếm thời gian đáng kể, hãy dùng MaxPool thay thế hoàn toàn:

```python
# Nếu phải chọn một, dùng GlobalMaxPooling duy nhất:
x = GlobalMaxPooling1D()(x)  # compile → max_pool kernel 7.8×
x = Dropout(0.3)(x)
outputs = Dense(n_classes, activation='softmax')(x)
```

---

## 5. Softmax — không cần lo

Softmax chỉ chạy một lần duy nhất trên vector 5 phần tử, dù chỉ đạt **1.4×** thì thời gian tuyệt đối vẫn rất nhỏ (tính bằng microsecond). Không cần thay thế.

    x = BatchNormalization()(inputs)
    x = MaxPooling1D(pool_size=2, padding='same')(x)  # 7.8×

    for i in range(4):
        residual = x
        s = 2 if i in [0, 2] else 1
        ks = 7 if i < 2 else 5         # kernel nhỏ hơn ở block sau

        x = BatchNormalization()(x)
        x = Activation('relu6')(x)     # 11.5×

        x = Activation('relu6')(x)

        x = Dropout(0.2)(x)
